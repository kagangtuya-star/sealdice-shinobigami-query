# 忍神速查插件

面向 SealDice 平台的 忍神规则查询插件，提供覆盖忍法、背景、谜团、敌人等多种数据表的统一检索体验，满足跑团主持人与玩家的即时查阅需求，具备多指令入口、高级过滤、全局速查与模糊建议等能力。

## 功能概览

- **多指令入口**：
  - `查<类别> [关键词] [#标签] [&分类]`（支持别名 `.q`）。
  - `.全查 <类别> <关键词>`：在指定类别内启用“全字段”搜索，覆盖描述、效果、备注等所有文本列。
  - 自然语言前缀：如 `查忍法 影分身`（无需点号）。
  - `速查 [类别] <关键词>`：跨库速查，类别可选。
- **统一搜索逻辑**：先按“名字”字段全局精确/包含匹配，再结合标签（`#`）与分类过滤（`&`），并按照匹配强度排序返回结果。
- **模糊建议**：未命中时返回 Levenshtein 距离最接近的候选条目，生成“或许你想查”列表，全域模式下亦会遍历所有字段。
- **结果展示**：
  - 单条结果：完整详情展示。
  - 多条结果：摘要列表 + 快捷提示（`.查XX` / `速查 XX`）。
  - 无结果：提供模糊建议或提示调整关键词。
- **数据覆盖**：忍法、背景、谜团、人格假面、惟神、奥义开发、外道忍法、妖魔武器、仪式忍法、战场、敌人、变调等多个数据库。

## 快速上手

1. **安装依赖**（需要联网）：
   ```bash
   npm install
   ```
2. **本地调试构建**：
   ```bash
   npm run build-dev
   node dev/shinobigami-query.js
   ```
   在 Node 环境下模拟指令输入，例如：
   ```js
   // 伪代码示例：请按 SealDice 平台的指令事件调用插件入口
   寄件器('.查 忍法 影分身')
   寄件器('.全查 忍法 火达摩')
   寄件器('速查 奥义开发 贯通')
   寄件器('查敌人 祈祷师')
   ```
3. **生产打包**：
   ```bash
   npm run build
   ```
   生成的产物位于 `dist/shinobigami-query.js`，可上传至 SealDice 插件目录。

## 指令与语法

### 1. 通用指令
- `.查 <类别> [关键词] [#标签] [&分类]`
- `.q <类别> ...`
- 示例：`.查 忍法 伤害 #鞍马神流 &花费:<=2`

### 2. 全字段指令
- `.全查 <类别> <关键词>`
- `.qall <类别> <关键词>`
- 示例：`.全查 忍法 火达摩`（在忍法中检索所有字段，含效果/备注等）

### 3. 硬编码快捷指令
- `.查忍法 影分身`
- `.查背景 长处`
- `.查人格假面 王者`
- `.查奥义开发 裁断`
- `.查外道忍法 战术爆击`
- `.查敌人 祈祷师`

> 如果直接输入 `.查忍法`（无参数）或 `.查 <类别>`（无关键词），系统会返回通用帮助说明。

### 4. 无前缀自然语言
- `查忍法 影分身`
- `查敌人 祈祷师`
- `查外道忍法 电磁结界`

同样，若只输入前缀不带关键词，将回复指令帮助。

### 5. 速查指令
- `速查 影分身`（跨库查找）
- `速查 忍法 影分身`
- `速查 奥义开发 贯通`

速查会先全局匹配“名字”，若找到则直接返回相应类别；若没有，则逐类匹配并按照设定优先级（忍法 → 背景 → 谜团 → 人格假面 → 惟神 → 奥义开发 → 外道忍法 → 妖魔武器 → 仪式忍法 → 战场 → 敌人 → 变调）返回首个命中结果。

## 查询语法说明

- **关键词**：可以是任意文本，多个词语按“与”逻辑匹配（所有关键词都需出现在同一条记录中）。全域模式会在该类别的全部字段中查找关键词。
- **标签（#）**：用于模糊匹配标签字段，如 `#鞍马神流`、`#类型:异人`，支持 `#标签值1/标签值2` 多选。
- **分类（&）**：用于精确或范围过滤，支持运算符：`= != > < >= <= contains`。
  - 示例：`&花费:<=2`、`&威胁度:>=3`、`&类型:contains:强化`
  - 数值字段会自动按数字比较。
- **序号精确匹配**：若关键词为纯数字，则直接按“序号”查找。

## 开发指南

- 插件入口位于 `src/index.ts`，分类配置在 `src/data.ts`。
- 搜索、格式化、解析等模块分布如下：
  - `src/types.ts`：类型定义。
  - `src/parser.ts`：指令语法解析。
  - `src/search.ts`：过滤、排序与模糊建议。
  - `src/formatter.ts`：结果文本输出。
  - `src/utils.ts`：工具函数。
- 更新数据库时，请在 `database/` 目录添加对应 JS 文件，并在 `src/data.ts` 中注册类别、字段与指令配置。
- 构建脚本位于 `tools/build.js`，输出文件名由 `tools/build-config.js` 控制，默认产物为 `shinobigami-query.js`。

## 发布流程

1. 运行 `npm run build` 生成 `dist/shinobigami-query.js`。
2. 校对 `header.txt`、`package.json` 中的插件信息（名称、作者、版本、描述）。
3. 将产物上传至 SealDice 插件目录或提交至官方插件仓库。
4. 在 SealDice 测试服中验证指令功能，重点测试：
   - `.查`、`.查XX`、`速查`、`查XX` 指令的空白处理与帮助提示。
   - 多条结果时的提示语是否简洁。
   - 新增数据类别（谜团、外道忍法、敌人等）的查询准确性。

## Sealchat 术语表转换器

`database/convert-keywords.cjs` 用于将插件内各类别的 JavaScript 数据表转换为 Sealchat 术语表 JSON。转换器会读取 `database/` 下的 12 个数据表，提取主关键词与别名，将详情字段合并为带字段标记的 `description`，并生成稳定的记录 ID 与连续的 `sortOrder`。

### 使用方法

在仓库根目录执行：

```bash
node database/convert-keywords.cjs --cwd database \
  --template 术语测试-keywords.json \
  --out 完整术语库-keywords.json
```

若当前目录已经是 `database/`，可直接执行：

```bash
node convert-keywords.cjs
```

默认模板为 `术语测试-keywords.json`，默认输出为 `完整术语库-keywords.json`。命令行参数：

- `--cwd <目录>`：数据表与模板的工作目录。
- `--template <文件>`：Sealchat 术语表模板 JSON；模板第一条记录的元数据会作为默认值继承。
- `--out <文件>`：输出 JSON 文件路径；父目录不存在时会自动创建。
- `--help` / `-h`：显示用法。

输出记录包含 `keyword`、`category`、`aliases`、`description`、`sortOrder` 等字段。主字段中的换行内容会拆分为主关键词和别名；空关键词、只有单一非空详情字段的行会被过滤。更新 `database/*.js` 后重新运行转换器即可生成最新术语表。

转换器自带 Node 测试，可在仓库根目录执行：

```bash
node --test database/tests/keyword-converter.test.cjs
```
